# IPL Prediction System

A Machine Learning based IPL match prediction system built using Python and Streamlit.

## Features

* Predict IPL match winners
* Interactive user interface
* Team-wise analysis
* Match statistics visualization

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit

## Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Feature Engineering
4. Model Training
5. Prediction Generation
6. Streamlit Deployment

## How to Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
