# 🏏 IPL Match Winner Prediction System

A Machine Learning based web application that predicts IPL match winners using historical IPL match data.

## 🚀 Live Demo

https://ipl-prediction-system-27unvaxiqdkx7e6xnw2sfj.streamlit.app/

---

## 📌 Features

* Predict IPL match winner
* Toss winner & toss decision input
* Venue-based prediction
* Winning probability visualization
* Interactive Streamlit web interface

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Plotly
* Joblib

## ▶️ How to Run Locally

1. Clone repository

git clone https://github.com/AnshumanSingh06/IPL-Prediction-System.git

2. Open project folder

3. Install requirements

pip install -r requirements.txt

4. Run Streamlit app

python -m streamlit run app/app.py

---

## 📊 Machine Learning Model

The project uses a trained machine learning classification model to predict IPL match winners based on:

* Team 1
* Team 2
* Toss Winner
* Toss Decision
* Venue
